# 🚀 Kunal Singh Tanwar — Portfolio

A modern, high-performance portfolio website built with **React**, **TanStack Router / Start**, **Tailwind CSS**, and **Framer Motion**. Designed with a dark aesthetic, fluid micro-interactions, responsive typography, and mobile optimizations.

---

## 🌐 Live Preview

- **Local URL**: [http://localhost:3000](http://localhost:3000)
- **Production Server**: Node.js / Nitro SSR
- **Live Deployment Options**: GitHub Pages, Vercel, Netlify, Render

---

## ✨ Features & Highlights

- **Hero & Navigation**:
  - Clean, minimalist left-aligned navbar with responsive mobile drawer menu.
  - Bold typography with dynamic gradient fills.
  - Interactive avatar with subtle magnetic hover physics.
  - Direct quick-contact call-to-actions.

- **About Me**:
  - Scroll-triggered interactive text reveal animations.
  - Background ambient floating icon elements.

- **Skills Marquee**:
  - Multi-row continuous infinite looping marquees for AI/ML, backend, cloud, and tools.
  - Covers Python, TensorFlow, PyTorch, Keras, FastAPI, Docker, GCP, AWS, PostgreSQL, MongoDB, CI/CD, and more.

- **Experience & Education**:
  - Structured timeline of AI/ML engineering internships, production accomplishments, and responsibilities.
  - Academic background (Poornima University) and professional industry certifications.

- **Services**:
  - Machine Learning & Deep Learning model pipelines.
  - LLM integration, prompt engineering, and conversational AI.
  - Full-stack web application development with FastAPI and modern frontends.
  - Cloud deployment, containerization (Docker), and automated CI/CD pipelines.

- **Featured Projects**:
  - Sticky stacked project showcase with live interactive links and responsive previews.
  - **RoadBuddy**: AI-Powered Road Trip Planner (Full-Stack + ML).
  - **Text Summarization API**: Deep learning NLP pipeline.
  - **Fake News Detection**: NLP classification model.

- **Mobile First & Responsive**:
  - Adaptive viewport sizing (`100dvh`) preventing layout shifts on mobile address bars.
  - Responsive stacking, card gaps, and touch-friendly targets ($44\times44\text{px}$).

## 🚀 Getting Started

### Prerequisites
- **Node.js** (v18 or higher recommended)
- **npm** or **bun**

### Installation

1. Navigate to the project directory:
   ```bash
   cd Portfolio14-main
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

---

### 💻 Available Scripts

#### 1. Development Mode (Hot-Reloading)
```bash
npm run dev
```
Starts the Vite dev server at `http://localhost:5173` (or next available port).

#### 2. Production Build
```bash
npm run build
```
Compiles and bundles both client assets and the Nitro SSR server into `.output/`.

#### 3. Run Production Server
```bash
npm start
```
Starts the fast, optimized SSR server at `http://localhost:3000`.
